one generated bridge example: [`rxinfer/`](rxinfer/README.md), the Asia-network
GraphSpec → RxInfer.jl emitter output, regenerated byte-identically by
`tests/gnn/test_rxinfer_bridge.py`.

The exemplar GNN specs the pipeline runs live in
[`input/gnn_files/`](../input/gnn_files/INDEX.md), not here.
