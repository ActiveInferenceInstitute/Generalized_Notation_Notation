# Cognitive Effort

In the active inference account, a mental action such as redirecting attention
can require overcoming a habitual policy. In the Stroop task, naming the ink
colour of an incongruent word competes with the habit of reading the word.
The model uses the prior over policies to express habit and preferences over
outcomes to express task motivation.

- [Cognitive effort in active inference](README.md) introduces the account and its model components.
- [Cognitive effort as mental action](cognitive_effort_initial_paper.md) gives the full formulation and empirical analysis.
- [Stroop task effort model](stroop_effort_model.md) applies the account to colour naming.
- [Effort model](effort_model.md) provides a GNN scaffold for the precision account.
