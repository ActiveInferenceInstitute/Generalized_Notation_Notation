## Available Documents

- **[GNN Examples and Model Progression](gnn_examples_doc.md)**
- **[GNN Quick Start Tutorial](quickstart_tutorial.md)**

Both tutorials build a **discrete categorical** model first (`A`/`B`/`C`/`D`
keys). For the **continuous linear-Gaussian** kind (`F`/`H`/`Q`/`R`,
optionally closed-loop `goal_mean`/`control_gain`), the examples guide has a
dedicated section and runnable exemplars live under
[`input/gnn_files/continuous/`](../../../input/gnn_files/continuous/).
